Manifest changes only those 37 normalized local hashes. Public components,
Compat, guest media, configuration and snapshot bytes are unchanged.

176 candidate hunks represent 277 pre-change selected text-difference lines.
Fresh selected-body comparison confirms all 277 are removed, omitting unchanged
excluded bodies and separately verified line controls. This is not a claim of
277 fewer raw Git diff lines. Using
fixed-XP LF-normalized bytes and Git Myers `--no-index --numstat`, the 37-file
raw comparison changes from **+7260/-23469** to **+7131/-23355**:
**243 fewer added+deleted lines**. Excluded bodies are not audited or listed;
their byte content is unchanged. Raw matching includes their surrounding
context, so its alignment differs from a selected-body-only comparison.
For example gfx_updt.c's raw matching grows by five lines despite restoration
of its original blank/comment spelling; this is not a new executable patch.

Existing line controls are retained; 61 numeric anchors are calibrated against
exact retained XP lines in the affected segments. No new condition, exclusion,
line-control directive, helper or execution path is introduced. Code-token and
conditional-order comparisons pass for all modified files, ignoring comments,
whitespace and separately checked line-control values.
