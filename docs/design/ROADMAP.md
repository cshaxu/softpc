# Roadmap

## M0: Governance And Baseline

Establish NXVM-style authorities, queue discipline, and a recorded standalone
baseline without changing machine behavior.

## M1: Pristine Machine Recovery

Restore original SoftPC source ownership, create the port-ABI ledger, and move
standalone behavior out of machine source.

## M2: Independent Compatibility Host

Provide original host callback contracts for timing, BOP, media, rendering,
input, and audio without NTVDM dependencies.

## M3: NXVM-Style Runtime

Build one executor, bounded command/input queues, frame mailbox, and direct
launcher lifecycle over the recovered machine.

## M4: Responsive Frontends And Compatibility Proof

Replace transitional console/window loops, prove RDP interaction and original
renderer operation, then close with real A:/C: and Windows Setup evidence.
