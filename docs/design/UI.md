# Product UX

Double-clicking either launcher opens the SoftPC monitor. `start`, `pause`,
`resume`, `stop`, `reset`, and floppy insert/eject remain monitor operations.
The fixed adjacent INI is the only configuration input; no profile chooser or
session manager is introduced.

Console and window are equivalent views of one VM. Window input must be
responsive over RDP, and graphics/text output must be presented from published
snapshots rather than direct reads of the running machine.
