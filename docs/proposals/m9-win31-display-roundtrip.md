## 已知复现与对照

1. 在 Win3.1 图形界面打开 MS-DOS 提示符，进入客户机全屏文本状态。
2. 按 CAF（Ctrl+Alt+F）切换到宿主 Window。
3. 再按 Alt+Enter 返回全屏文本提示符。
4. 执行 `cls`，观察到内容残留、显示未正确刷新。

普通 DOS 下 `cls` 已通过用户及原生包测试，因此不能把此问题等同于
通用 CLS 清屏故障。优先调查显示模式往返后的画面/状态失配，而非
修改命令或凭猜测清空缓存。这里的全屏是客户机显示状态，不是要求新增
宿主无边框全屏功能。
